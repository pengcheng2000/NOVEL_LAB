# COPYRIGHT_RULES — 版权与原创性边界规则

## 原则

研究参考小说的目的不是"换名字抄剧情"，而是提取**可复用的抽象故事机制**。

## 三层区分

### 1. 可学习的抽象机制（GREEN）
- 身份跌落 → 成长 → 地位反转
- 信息差爽点 / 不可靠叙述 / 封闭竞争
- 暧昧关系推进 / 公开羞辱后的延迟兑现
- 普通人进入异常世界 / 小人物完成不可能任务
- 阶层差异制造爱情张力
- 章末悬念 / 多次假答案后揭示真相
- 其他结构级、心理级机制

### 2. 组合识别度（YELLOW）
- 特定机制的**特定组合方式**若具有强识别度，直接照搬组合仍可能被指认
- 使用时需改变：组合顺序、题材载体、人物配置、情绪基调中至少两到三项

### 3. 不可复制的具体表达（RED）
- 人物姓名、地名、组织名
- 独特世界观专有名词
- 经典台词、标志性意象
- 高度独创的能力/设定体系
- 连续的标志性剧情链（即使改名）
- 特定人物关系组合（若高度指向原著）
- 标志性场景的视觉/桥段复刻

## 分析文件写作规则

- **禁止大段复制小说原文。**
- 证据优先使用：章节号、章节标题、剧情位置、简短概述。
- 确有必要时仅引用极短片段（单处 ≤ 1 句），并标明出处。
- 分析阶段允许准确描述原作机制，但 Story DNA 输出必须进一步抽象。

## 源文件规则

- `01_reference/` 中的完整小说源文件受版权保护，已加入 `.gitignore`。
- **禁止从盗版网站下载源文件。**
- 源文件缺失时在 `PROJECT_STATUS.md` 标记 `MISSING_SOURCE`，不伪装已阅读全文。
- 用户提供的合法副本（自有购书、公开试读章节、公开领域文本）为唯一来源。

## 原创阶段规则（未来适用）

- 原创故事必须经过 `originality-reviewer` 审查。
- 审查维度见 `.claude/skills/originality-reviewer/SKILL.md`。
- 该审查是创作风险筛查工具，**不是法律判定工具**。
