# Relationship Engine

## 总原则

关系不等待读衣才发生。债务、征收、合伙生意、亲属权利和事故责任让人物即使在晴天也必须见面。每 3 章至少一条长期关系发生权力变化；每次亲密兑付必须同时增加新的风险或责任。

## 1. 谢念 × 周序：事实同盟 / 慢热关系

- **Initial State**：征收协调员与拒绝签字的店主；双方都怀疑对方借旧事谋利。
- **Attraction / Need**：谢念需要他的档案与程序能力；周序需要她手中的事故衣物。吸引来自对物证的共同敏感，以及对“谁有解释权”的持续分歧。
- **Conflict**：她相信主观记忆能补档案，他只承认可复核证据；他的项目会拆店，她的调查可能坐实其父过失。
- **Secret**：周序藏着父亲临终录音；谢念隐瞒自己曾主动请求遗忘。
- **Power Balance**：前期他掌握征收流程，她掌握衣物；中期他延缓拆除而承担职业风险，她越界读衣伤害其信任；后期二人必须互交最不利证据。
- **Turning Points**：Ch3 首次勘测冲突；Ch8 共同核验外卖雨衣；Ch13 他公开父亲录音的一半；Ch16 谢念承认主动遗忘；中点后共同寻找第七衣。
- **Breaking Point**：谢念未经完整同意利用反光雨衣取得周父记忆，周序退出同盟并恢复拆除程序。
- **Possible Resolution**：不是“他替她记住一切”，而是双方在知道对方有错后仍决定共同生活；感情可成立也可停在可信同盟，不影响主线闭合。
- **无魔法仍有戏**：征收谈判、事故档案、父辈责任与店铺经营足以持续冲突。

## 2. 谢念 × 唐荔：合伙友情 / 保护性背叛

- **Initial State**：多年好友重新合伙；唐荔负责改衣与直播，谢念负责选品与运营。
- **Attraction / Need**：一个敢拆，一个会读；双方共享阶层处境与少年记忆。
- **Conflict**：唐荔要现金流、曝光和改造，谢念要谨慎、保留和隐私。
- **Secret**：唐荔参与九年前的封存仪式，并持有谢念校服的袖章。
- **Power Balance**：唐荔掌握日常生意与真相，谢念掌握店铺产权与规则入口；彼此都不能单独让店活下去。
- **Turning Points**：Ch2 加入；Ch6 为曝光偷拍视频；Ch10 承认知道三日失踪；Ch15 秘密曝光，友情断裂；Ch18 她把袖章和选择权交还。
- **Breaking Point**：谢念发现唐荔九年来每次谈到陈橙都在配合外婆改写她的记忆。
- **Possible Resolution**：唐荔不求一句原谅，而是退出“替她决定”的位置；两人以重新签订合伙协议而非拥抱完成修补。
- **无魔法仍有戏**：二手生意、品牌路线、旧街去留与友谊债均可独立推进。

## 3. 谢念 × 谢岚：母女 / 离开与控制

- **Initial State**：九年只剩节日转账与简短语音；谢念认定母亲在事故后另过人生。
- **Attraction / Need**：谢念需要母亲的证词与黄色雨衣；谢岚需要确认女儿不会被店吞掉。
- **Conflict**：母亲以卖店作为援助条件，女儿以找回记忆作为关系条件。
- **Secret**：谢岚同意过封存，并在事故中先救女儿；谢念记得自己求过遗忘却装作全不知。
- **Power Balance**：谢岚有资金与撤回权，谢念有遗产处置权；任何一方都不能强迫另一方交衣或原谅。
- **Turning Points**：Ch7 视频通话拒绝；Ch12 回城；Ch14 撤回雨衣；Ch16 母女第一次交换各自最不利事实；后期共同对质林素云的记录。
- **Breaking Point**：谢念跨过活人同意线；谢岚当众揭露她曾主动请求遗忘。
- **Possible Resolution**：母女不恢复成理想家庭，只建立可兑现的新关系：每月见面、不给钱代替解释、不拿离开惩罚对方。
- **无魔法仍有戏**：赡养、债务、店铺产权、长期缺席与事故责任足够形成家庭剧。

## 4. 谢念 × 秦沛：资源依赖 / 叙事权竞争

- **Initial State**：收购者与负债店主；秦沛以外婆故人身份取得信任。
- **Attraction / Need**：谢念需要资金、流量和第七件衣；秦沛需要店址、账本和谢念这个合法继承人。
- **Conflict**：谢念认为记忆只能在关系中自愿交付；秦沛认为经合同授权即可公开，让无名者被看见。
- **Secret**：秦沛因非法代看失去了对妹妹的悲伤，并藏有事故衣物。
- **Power Balance**：她能买下债权与舆论，谢念能拒绝店主登记；中期秦沛公开传闻迫使店铺爆红，双方力量倒转。
- **Turning Points**：Ch5 收购；Ch9 提供旧账线索；Ch14 流量危机；Ch17 拿第七衣交换账本；后期她首次撤回一份已签署授权。
- **Breaking Point**：秦沛直播暗示“雨夜读衣”，导致无关者涌入并有人试图抢衣。
- **Possible Resolution**：她放弃特殊能力商业化，但建立普通人口述与衣物档案项目；与谢念保持价值竞争而非洗白成朋友。
- **无魔法仍有戏**：小店与平台、隐私与内容、现金流与伦理的冲突独立成立。

## 5. 谢念 × 林素云：死后母职 / 继承与反抗

- **Initial State**：谢念把外婆视为唯一没有离开自己的人。
- **Attraction / Need**：她用继承店铺延续外婆，也想从遗物中获得最后解释。
- **Conflict**：每条新记录都证明外婆的爱与控制是同一动作。
- **Secret**：外婆隐瞒谢念主动请求遗忘，又长期拒绝归还，最终还把未完成任务写成遗嘱。
- **Power Balance**：死者不能回应，却通过债务和规则占据权力；谢念只有通过拒绝照单全收夺回解释权。
- **Turning Points**：首笔“谢念未还”；发现删页；理解外婆曾救她；得知外婆也在失去对谢岚的情感；终局改写店规。
- **Breaking Point**：谢念发现外婆最后三次电话不是告别，而是请求她终止特殊读衣能力（口径依 `06_secrets/SECRET_MATRIX.md` Late 层 Ch58 录音；2026-09-14 Canon Update 统一）。
- **Possible Resolution**：她保留外婆的深蓝罩衫，但拆掉神圣化的试衣帘；爱被保存，制度被终止或重写。
- **无魔法仍有戏**：照护、遗产、代际控制和未赶上最后一面本身成立。

## 关系节奏纪律

- 爱情线与主谜异频：主谜大揭示时只埋关系问题，不同步发糖。
- 友情必须经历一次不可快速修复的价值背叛。
- 母女和解不能由一段记忆自动完成。
- 秦沛每次提供资源都必须改变权力平衡，不能只当反派送线索。
- 林素云的每次“隔空出现”最多回答一个问题，同时制造一个更具体的新责任。
