# 《雨天旧衣店》— Core Identity

> Phase 5 定稿基线。若后续文件与本文件冲突，以本文件为准并记录变更。

## 30 秒版本

栖州市回潮里有一家只在自然降雨时接待特殊客人的旧衣店。衣服若在一个人无法说出口的选择里留下了“折痕”，与他关系最深的人穿上它，就会经历那段**主观记忆**；代价是把自己一段同样不肯面对的记忆寄存在店里。外婆去世后，27 岁的二手服饰运营谢念继承店铺，发现自己早在十八岁就是一名“未还账”的客人。距离店铺被拍卖、街区被拆只剩九十天，她必须找回与一场雨灾有关的七件衣服，拼出自己被拿走的三天，并决定：真相应被看见，还是有些遗忘本就是一种救命。

## 最终一句话 Hook

**她继承了一家只在雨天读取旧衣记忆的店，却在账本上发现：自己十八岁那场雨，至今“未还”。**

## Core Premise

旧衣能保存穿衣者在重大选择中未曾说出口的主观记忆。谢念以店主身份替人与旧日相认，同时追查七件与“7·18 回潮桥积水事故”有关的衣服；每完成一笔别人留下的账，她都会更接近自己被外婆封存的记忆，也更接近失去外婆的风险。

## Core Fantasy

读者可以通过最贴身、最日常的物件，进入一个人从未解释过的那一刻；不是复活死者，也不是改写过去，而是获得一次迟到的理解，并在现实里作出新的选择。

## Core Emotional Promise

每个重要单元交付一种不同的情绪结果：理解不必等于原谅，真相不必带来和解，告别也不要求忘记。全书最终交付的是：一个人即使失去部分记忆，也能由当下选择和他人共同见证而继续成为自己。

## Core Mystery

九年前的雨夜究竟发生了什么？为什么谢念丢失了三天记忆？外婆为何登记七件“未还衣”，又为什么宁可让女儿离家、让外孙女恨自己，也不肯归还那段记忆？

## Core Theme

**记忆不是事实的全部，也不是爱的唯一凭证；真正的承担，是知道过去之后仍为今天的选择负责。**

## Core Conflict

谢念想用旧衣找回被夺走的过去，却必须使用一个会继续拿走记忆、且只能提供主观证词的系统。外部的九十天拆迁与债务逼她加速；母亲、朋友、周序和秦沛各自握有一版真相，并有充分理由阻止或利用她。

## Core Reader Promise

- 每 2–3 章完成一次“读衣—验证—现实后果”的有效兑付，不保证温情结局。
- 每个单元至少改变主线、关系、规则或人物中的两项。
- 七件衣服提供可见进度；每一件都推翻上一版雨夜真相的一部分。
- 终局不靠新增规则或万能记忆，而靠七个有限视角、现实证据和谢念自己的选择汇合。

## 类型与边界

- 类型：当代都市现实质感 × 轻超自然 × 家庭悬疑 × 群像成长。
- 主情绪：好奇、亲密、失落、承担；辅情绪：幽默、愤怒、恐惧、小胜。
- 不是：万能通灵、替死人传话、每集必哭的治愈合集、可交易的记忆当铺、重选人生故事。
- 叙事优先级：人物因果 > 主线悬疑 > 单元情绪 > 视觉奇观。
