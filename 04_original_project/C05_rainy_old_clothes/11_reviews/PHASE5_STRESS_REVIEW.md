# Phase 5 Stress Review

## 总判定

Phase 5 已把 Candidate 最大缺陷——“陌生人温情短篇拼盘”——从结构上降为可管理风险，但没有消灭品类疲劳。项目可以进入正文准备；真正成败取决于是否执行反单元化纪律，而不是继续增加设定。

## 读者攻击

### 为什么可能不好看？

雨、旧衣、外婆、失忆都天然“有气氛”，也容易只有气氛。若记忆段比现实行动更长，读者会把谢念当播放器；若每次真相都证明死者有苦衷，情绪会迅速通胀。

**已修复**：标准循环把“读衣”放在中点，结尾必须是现实行动；首卷包含不和解、拒看、申诉、假衣反制和友情证词。40% 单元不得以和解结束。

### 为什么 20 章以后可能重复？

换年代和换衣服只是换皮。核心动作若仍是“穿上—看见—哭”，第十次必然失效。

**已修复**：六种语法轮换；第二部后单元数量下降，人物与事故复核接管主导；每单元至少反哺两项，连续三章不得有任一引擎停摆。

## 编辑攻击

### 为什么人物可能没魅力？

“善良、共情、为别人付出”是被动美德。谢念如果总是正确，只会成为作者的温柔代言人。

**已修复**：她有控制性善良、证据成瘾、虚荣与自利目标；中点会违规读衣并失去周序信任。她的现实鉴衣、平台运营和经营决策提供非魔法行动。

### 为什么主线仍可能太弱？

七件衣如果只是按序播放，仍是一份加长播放列表；九十天拆迁若每卷末才出现，也只是外部闹钟。

**已修复**：七衣的取得由核心人物同意权控制，每件都改变关系权力；债权、征收、普通业务和事故档案按明确日期推进。最终责任链需现实证据，不靠集齐自动通关。

### 最大的新风险：主线过强反吞作品气质

事故复核、责任链和拆迁程序可能把故事推成社会派调查，旧衣与日常生活反而沦为线索工具。

**控制措施**：全书主谜场景不超过 45%；每 4 章至少一场无魔法的经营/关系日常；事故公共责任只求更正，不发展成幕后犯罪阴谋。

## 影视制片人攻击

### 为什么爱情可能多余？

周序若只是帮查档案、相信女主、最后接住她，就是功能型男友；“父亲被事故牵连”也容易显得为了 CP 强行绑定。

**已修复**：他的目标可能被七衣伤害；他握有不利录音并会因谢念越界退出。他的弧是接受父亲真实过失，不以爱情解决。删除恋爱结果仍不影响事故与店铺主线，证明爱情是增益而非支柱。

### 为什么影视化可能失败？

多个年代、持续雨景、洪水事故和衣物特写都比纸面昂贵；“记忆逐渐失去情绪”难以画面化。若靠旁白解释，剧会失去戏。

**部分可修复**：第一季只需 3 个完整年代单元；记忆代价通过行为错位、味觉缺失、认不出习惯而非抽象独白表现；洪水真相分六个局部视角拍摄，不做一次性大场面。仍需承认雨水连续性和年代服装是预算风险。

## AI 视频创作者攻击

### 为什么 AI 路线可能失败？

梦境换风格减少长期场景一致性，却增加每集资产重建；衣料、手部缝补、准确汉字、雨水和多人关系表演都是高失败点。美术漂亮不等于一集可看。

**部分可修复**：固定店景与核心角色参考优先；文字账本、店招和收据用后期合成；梦境以单人主观镜头、物件和声音为主；第一季限制常驻 6 人、单元客 2 人。不得为了生成方便删掉母女、友情或同意冲突。

## 规则攻击

### 为什么能力规则可能成为漏洞？

读者会问：为何不找别人代看、为何不复制、为何不用活人衣调查、为何记忆不能当证据、为何人工降雨无效、为何每次恰好看到有用内容。

**已修复**：关系资格、店主代看付费、活人撤回、一衣一次、主观偏见、自然雨+固定店址、现实证据另找均已写成硬规则。衣服只显示“关系折点”，因此有用但不精确；无用、误认和正确拒绝已在首卷示范。

### 仍不可完全修复的规则风险

自然雨与旧址为何能触发不提供终极解释。若正文反复暗示“真正起源是大秘密”，读者会期待不存在的答案。

**纪律**：前三章明确最早记录而非起源；全书谜题只承诺规则边界与家族使用史，不承诺宇宙解释。

## 四视角剩余致命风险

| 视角 | 当前最大风险 | 状态 |
|---|---|---|
| 读者 | 情绪与单元语法重复 | 可管理，不可根除 |
| 编辑 | 事故调查压过生活与人物 | 已设 45% 上限，需正文监测 |
| 制片人 | 年代/雨景/洪水的隐性成本 | 需改编期缩场，不影响小说立项 |
| AI 创作者 | 美学一致性与细节失败率 | 可用固定资产和后期文字控制 |

## Phase 5 修复验收

- [x] 删除单元仍有完整人物、秘密、关系、悬疑与成长线。
- [x] 旧衣 20 问均有明确答案，且限制能制造冲突。
- [x] 六名核心角色各有欲望、秘密、矛盾、利益和弧。
- [x] 至少四条关系通过无魔法测试。
- [x] 单元反哺有硬门槛和章级验证。
- [x] Early/Mid/Late/Endgame 秘密分层，不把所有答案拖到结尾。
- [x] 前 20 章无连续三章缺少明显推进。
- [x] 原创性审查无 RED 项。
- [x] 未写正式正文、剧本或视频 Prompt。

## Go / No-Go

**GO：已具备进入 Phase 6 正文生产的 Story Bible 条件。**

进入正文前只需把本文件列出的三项设为生产监控指标，而非继续扩写世界观：单元语法重复率、主谜场景占比、谢念主动行动占比。当前不启动 Phase 6。
