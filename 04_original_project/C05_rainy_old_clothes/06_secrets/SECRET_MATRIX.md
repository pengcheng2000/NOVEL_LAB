# Secret Matrix

## 披露原则

- 秘密按 Early / Mid / Late / Endgame 分层；每层必须回答旧问题并改变人物权力。
- 读衣只提供主观证词，任何公共事实至少需要一项现实证据核验。
- 不允许终局新增第八件衣、新店规或隐藏幕后凶手。

## 红鲱鱼控制

- 秦沛不是事故幕后凶手；她的威胁是叙事权商业化。
- 林素云没有制造事故；她的责任是事故后的控制。
- 周序父亲既非全然无辜，也非单一罪人。
- 陈橙没有秘密存活、双胞胎或预谋自杀。
- 超自然能力来源不在终局突然人格化，也没有“店在选人”的神谕。
