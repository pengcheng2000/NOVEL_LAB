# Unit-to-Mainline Rules

## 准入门槛

一个单元只有满足以下条件才进入大纲：

1. 对“谁有权看”存在真实争议。
2. 读衣结果会导致一个不可撤销的现实行动。
3. 情绪结论不能仅是“原来他爱我”。
4. 至少推进下列 **2 项**；A/B/C 中至少一项：

| 代码 | 推进项 | 合格标准 |
|---|---|---|
| A | 主角成长 | 迫使谢念选择、越界、认错或改变工作方式 |
| B | 主线秘密 | 增加/推翻事故、七衣或外婆行为的一条具体信息 |
| C | 核心关系 | 改变信任、利益或权力，不能只增加好感 |
| D | 能力规则 | 通过代价验证一个此前未知的限制或例外 |
| E | 世界真相 | 推进店铺历史、征收、平台或旧衣现实生态 |
| F | 长期对手 | 增加秦沛的资源、正当性或威胁 |
| G | 未来伏笔 | 留下可在 5–20 章内回收的物件/决定 |

## 单元卡模板

```text
衣物 / 权属：
承衣人及资格：
人物现在想要什么：
记忆的主观偏差：
现实核验动作：
不可逆后果：
语法类型：误解/调查/冲突/拒绝/反向/公共后果
推进项：A–G（至少2项）
情绪色：不得与上一单元相同
结束时谁的权力上升：
```

## 反重复配额

- 连续两个单元不得都以哭泣、拥抱、道歉收束。
- 每四个单元至少一个没有触发成功，一个由人物主动拒看。
- 每四个单元至少一个产生喜剧/经营小胜，一个产生愤怒或公共后果。
- 每六个单元至少一个由常驻人物发起，一个让谢念成为被调查对象。
- 年代变化只是美术变化，不计“换语法”。
- 单元客人结案后若不回场，不得占用超过 3 章。

## 主线焊接方式

1. **物件焊接**：普通客衣含寄雨行旧标签、事故雨痕或核心人物改补。
2. **人物焊接**：客人与更新项目、核心角色家庭或旧事故存在现实关系。
3. **规则焊接**：单元发现的限制，稍后成为七衣调查的障碍。
4. **代价焊接**：谢念失去的记忆直接影响下一段长期关系，而非只做结尾惊吓。
5. **后果焊接**：读衣引发投诉、报警、直播、赔偿或征收变化。

## 淘汰测试

出现任一情况即删除或重构：

- 换一件衣服、一个年代、一个客人，剧情功能完全不变。
- 梦境拿掉后，现实人物没有任何新选择。
- 单元只为解释设定或提供泪点。
- 谢念可以不在场且主线无损。
- 所有冲突都因“大家不把话说开”，而没有权利、利益或羞耻阻力。

## 单元审计表

每完成 5 个单元，检查：A–G 是否有任何一项连续 5 次未推进；核心六人是否有人连续 6 章不产生行动；是否连续 3 章没有明确 Goal、Reward 或 Ending Hook。任一命中，先改结构，不靠新增客人填空。
