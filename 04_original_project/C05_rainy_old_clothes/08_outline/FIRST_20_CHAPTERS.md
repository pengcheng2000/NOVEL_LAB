## 推进密度检查

- Ch1–20 每章均推进 Goal，且至少包含人物/关系/信息三项中的两项。
- 无连续 3 章只处理客人：Ch5–6 后 Ch7 转长期对手；Ch8–9 后 Ch10–13 转友情/家庭/主线。
- 单元结果轮换：不和解（Ch2）、拒看/当面对话（Ch5–6）、现实申诉（Ch8–9）、误认喜剧（Ch10）、假衣公开反制（Ch14）、核心关系读衣（Ch16–18）。
- 情绪轮换：诡异 → 克制 → 程序冲突 → 好奇 → 青春对立 → 商业诱惑 → 调查 → 幽默 → 家庭愤怒 → 公开胜利 → 友情背叛 → 身份反转 → 经营小胜。
