# 林素云

- **身份**：1949 年生，2025 年去世，75 岁；寄雨行第二代店主、裁缝与遗物整理人，1988 年接店。
- **欲望**：让女儿与外孙女活过 2016 年事故，并在死前把七笔未还账归位。
- **秘密**：她把一次应急保护变成九年控制：删改承衣簿、隐瞒谢念曾主动请求遗忘、拒绝归还记忆，也未告诉谢念代价正在侵蚀自己对女儿谢岚的情感。
- **矛盾**：她教别人尊重旧物的主人，却把至亲的记忆当成自己可处置的遗产；她确实救了谢念，也确实伤害了她。
- **与谢念的利益关系**：死后仍通过债务、店规和七衣影响谢念，但留下的每条记录都必须被视作有立场的证词。
- **独立弧（死后重估）**：圣人外婆 → 可疑守秘人 → 控制者 → 一个在灾难中做错选择、之后又不敢承认的人。终局允许理解，不提供无条件免责。
