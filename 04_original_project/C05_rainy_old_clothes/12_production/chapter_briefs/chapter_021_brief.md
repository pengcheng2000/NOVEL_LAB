# Chapter 021 /《门外的新衣》

## Chapter Role

第二部《返潮》Opening：让 Ch20 打开的普通公共入口第一次产生无法靠《服务须知》一句话解决的现实冲突，建立“现持有人可以要求修衣，但未必可以买到前穿衣人的公开叙事权”这一新部问题。

## Level

IMPORTANT

## Writer Reasoning

MEDIUM

## Pure Han Target

3,800–4,300 纯中文汉字（按 `[\u4e00-\u9fa5]` 统计）。

## Opening State

- Ch20 后次日上午；寄雨行只获得本地小范围关注，普通订单略增。
- 唐荔负责前台做工与排期，谢念负责经营边界与资产；私人友情冻结。
- 秦沛团队需要首轮普通修补内容；余禾仍只在外堂协助。
- 灰工装已退回秦沛仓储，第一格资格未解决；9/5 不变。

## Core Question

一件通过普通交易买来的旧衣，现持有人取得了要求改衣的权利，是否也取得了公开前穿衣人生活痕迹的权利？

## Scene Sequence

1. **Opening Image**：前堂新增少量待回复咨询与旧衣，但没有爆单；唐荔原有工单、新合作询问和门外施工通道挤在同一日常空间。
2. **经营分工**：余禾整理普通咨询与是否同意拍摄，唐荔按工时筛选订单；谢念要求把来源和拍摄范围分开问，三人出现效率压力。
3. **梁女士到店**：她带来普通二手渠道购得的暗绿棉夹克和常规交易记录，要求改短袖长；她真实喜欢衣物、愿意付普通工费，也同意拍摄修补过程。
4. **普通检视**：只看尺寸、磨损和可见修补痕迹，不拆夹层、不判断留痕衣、不接触超自然流程。唐荔认为可排工，谢念注意到这件衣已有他人长期使用痕迹。
5. **内容入口**：秦沛团队只取普通前堂素材/预告画面；灰工装、账本、证词和后堂均不入镜。秦沛认为现持有人同意足以启动普通内容。
6. **B线反照**：谢念在私有判断中意识到“持有、购买、穿过”可能分属不同的人；只轻触第一格方法问题，不推进实物。
7. **Ending**：预告画面中的可见修补痕迹被前穿衣人的成年女儿认出，对方公开提出来源与隐私异议；不以神秘电话或身世秘密作钩。

## A/B/C Line Allocation

- A 线（公开业务 / Consent–Source）：55%。
- B 线（第一格资格方法）：20%。
- C 线（经营 / 9/5）：25%。

## Evidence State

- 梁女士可证明当前普通交易与占有来源，但不能证明前穿衣人同意公开经历。
- 可见修补痕迹只支持衣物曾被长期使用/修过；不推出前穿衣人身份或故事。
- 第一格无新物证、无新证词、无新接触权。

## Relationship Movement

- 谢念 × 唐荔：出现“先排活还是先问清来源/拍摄范围”的职业摩擦；不升级私人冲突。
- 谢念 × 秦沛：有限合作第一次进入执行分歧，但尚未破局。
- 余禾：恢复普通运营存在感，不进入秘密层。

## Reveal Budget

- 新增长期事实：最多 1 项——公开合作的第一批询问中出现前穿衣人隐私异议。
- 主线 Reveal：0。
- 关系状态变化：最多 1 项（谢念/秦沛执行分歧显形）。

## Read Budget

- `READ COUNT = 0`
- `QUASI-READ = 0`
- `PLEDGE = 0`
- `Cost = NONE`

## Memory Segment Budget

NONE

## Exact Detail Budget

允许：`9/5`（最多一次）；现有角色、店铺与平台名称；“梁女士”这一姓氏称呼。

禁止：交易日期/价格、订单数量、播放/粉丝数据、平台工单号、身份证信息、前穿衣人姓名年龄职业、施工编号。

## Rule Budget

- `NEW RULES = 0`。
- 只体现公共经营政策与内部受理资格并非一套体系。
- 不展示多人穿衣、人工雨、只寄不看等未公开规则。

## Long-Term Fact Boundary

可具体化：梁女士通过普通二手渠道买到暗绿棉夹克；愿意普通改衣与拍摄；异议方凭可见修补痕迹认出衣物并声称前穿衣人仍在世、未同意公开。

禁止具体化：最终物权归属、卖方是否违法、前穿衣人的完整经历、衣物是否为留痕衣、任何旧衣记忆内容；孙正/灰工装新事实。

## Must Keep

- Opening 规模小而复杂，不写人山人海或爆单。
- 梁女士不是骗子，异议方也不是自动正确；双方诉求均有现实基础。
- 普通修补同意与内容公开同意第一次被拆开。
- 余禾只处理咨询、排期和拍摄标记。
- 店门外仍有施工/通行现实，不让经营脱离 9/5。

## Must Not Reveal

- 读衣能力、《承衣簿》、第一格/七格不得被梁女士、异议方、余禾、周序或秦沛新增知晓。
- 不推进唐荔动机、袖章、七日约定、封存仪式、周父后半录音、缺页、8 万元或红外套衣主。
- 不让谢念作法律结论。

## Ending Hook

公开合作本身产生第一项来源异议：一件已经被买走的衣，前穿衣人的生活痕迹是否仍能说“不”。Hook 来自公共入口的后果，不来自超自然异象。

## Next Chapter Interface

Ch22 让梁女士、异议方、唐荔、秦沛围绕修补、拍摄与来源提出不同要求；谢念必须作出暂停哪一部分、保留哪一部分的具体决定。

## Fail State

把新部开场写成热闹接单蒙太奇，或让谢念用一句“有/无授权”立即判完，都会使 Part II 发动机失败。
