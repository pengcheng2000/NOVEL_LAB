# Chapter Acceptance Standard

> 适用于所有章节。第一章额外承担世界入口、主角吸引力、异常证明与核心问题建立，因此任何单项低分都不能仅靠平均分掩盖。

## 评分方法

每项 1–10 分。10 分表示高度有效且几乎无需修改，不是常态目标；7–8 分是可出版方向的稳定完成，6 分表示可识别但明显不足，5 分及以下表示功能失败。

| 维度 | 检查问题 |
|---|---|
| Hook | 前 500 字是否出现具体冲突、异常、欲望或承诺？ |
| Clarity | 人物在做什么、为什么做、时空与物件关系是否清楚？ |
| Character Appeal | 谢念是否同时表现能力、缺口与可继续观察的矛盾？ |
| Groundedness | 钱、工作、空间、天气、手续与生活细节是否真正约束选择？ |
| Dialogue Naturalness | 人物是否像现实中的中国人说话，并具有可区分声音？ |
| Emotional Engagement | 情绪是否由关系和行动产生，而非由旁白要求读者感动？ |
| Mystery | 是否回答一个问题并留下更具体的新问题，且没有叙述作弊？ |
| Information Density | 设定、人物、主线信息是否分配得当，无说明墙或关键缺失？ |
| Pacing | 每个场景是否有 Goal / Conflict / Change，关键选择是否获得足够篇幅？ |
| Ending Hook | 最后 500 字是否完成本章 Reward，并产生真实点击动力？ |
| Prose Quality | 语言是否清楚、有画面、有节奏而不炫技、不重复？ |
| Continuity | 时间、知识、规则、关系、道具与既定 Canon 是否一致？ |
| Originality | 是否保持本作五项组合签名，避免滑回通用治愈小店？ |
| AI-ness | 是否没有模板化排比、万能总结、同质对白、假深刻与机械节奏？10 分代表高度自然。 |

## 通过门槛

- 建议综合平均达到 **7.5**，但不机械追求全部 10 分。
- Hook、Character Appeal、Dialogue Naturalness、Pacing、Ending Hook、Prose Quality、Originality、AI-ness 均不得低于 7。
- Continuity 不以平均分抵消：出现实质 Canon 冲突即自动退回。
- 第一章必须清楚交付：清产目标、赵为民来意、第一次异常、谢念主动代理、代价、谢念未还；其中任一缺失即不通过。

## 必须退回 Gemini 重写

出现任一项即列入 `MUST FIX`：

- 谢念没有有效行动，只被客人、记忆或别人推动。
- 前 800 字仍只有天气、店铺背景或外婆回忆，核心冲突尚未出现。
- 对话不像真人，角色以完整观点互相演讲，或人物声音可以互换。
- 一次讲完能力起源、全部规则或九年前事故背景。
- 把记忆写成客观录像、亡者留言或可直接证明事实的证据。
- 章末无 Hook，或 Hook 只靠模糊不安、停电、昏倒等外加事故。
- 为隐藏秘密而写出谢念明知为假的内心断言。
- 连续大量 AI 套话、排比、总结升华、同长度短句或高频空泛比喻。
- 违反人物动机、知识状态、时间线、旧衣规则、秘密层级或伏笔计划。
- 第一单元以“原来母亲一直爱你”直接促成和解。
- 为制造惊奇新增 Canon 中不存在的规则、人物或秘密。

## Sol 编辑原则

Sol 的默认工作是诊断，不是接管正文：

1. 指出具体位置和症状。
2. 说明它破坏了哪项章节功能或读者体验。
3. 给出可执行修改方向及验收结果。
4. 仅在 Writer 无法理解节奏、声音或视角问题时提供短示范，通常 300–800 字。
5. 整章重写交回 Gemini，以维持 Main Writer 的文风连续性。

## 第一章批准前的最终五问

1. 如果删掉旧衣能力，开场的债务、清产与外婆旧诺是否仍有现实冲突？
2. 如果删掉雨景形容，异常是否仍由明确动作和规则成立？
3. 谢念是否因为自己的选择付出代价，而不是被随机选中？
4. “未还”是否同时回扣人物过去并打开下一章，而不是只有名词神秘感？
5. 读者是否想知道谢念为何欠账，而不是只想知道能力说明书？
