## Six-Point Acceptance Check

### 1. Length and Pacing — PASS

6,058 字比第一稿明显更好。职业细节只保留到能证明谢念判断力的程度；赵的退缩不再被多轮旁白解释；医疗回忆、能力规则和代价段均已收紧。异常仍约在全章 29.6% 出现，但前段已有“下一位店主”、遗物争议、债务催收与赵的母子怨结，阅读拉力足够，不需要机械前移或重排。

### 2. Story Flow — PASS

各环节由人物行动推动：赵用旧诺阻止关店，谢念因外婆针法留下衣物，异常使规则从传闻变为现实，赵不肯押真正旧物，谢念主动接下代价。记忆中断后，赵选择留下大衣等待续读；代价再逼谢念翻账簿。Beat 之间具有因果，不是清单式串联。

### 3. Xie Nian — PASS

谢念同时表现出务实、职业判断、债务压力、对外婆死亡的回避、替别人承担的控制欲和主动选择。她押黑开衫不是作者强迫：她有合法拒收机会，唐荔也提供了退出路径，但外婆的针脚、未接电话的愧疚和“我能控制损失”的错误自信共同驱动她继续。

### 4. Birthday-Noodle Cost — PASS WITH TWO LOCAL FACT FIXES

核心机制成立：记忆被锁定为去年三月、谢念 26 岁、她确实穿着黑开衫、外婆病后仍为她做面，并与店铺债务和临终愧疚相连。她保留碗、面、动作和哭过的事实，却失去味道与当时情绪的所有权，清楚、有痛感，没有再用多组解释把效果说死。

年龄正确：谢念生于 1998-03-11，2024 年 3 月满 26 岁。需要删除错误的“周日”（2024-03-11 为周一）并修正未经设定的“念娣”称呼。

### 5. 1988 Memory — PASS

两张硬座票、湿冷风雪、蜂窝煤味和递票动作构成有效信息单位；“不能留”“来不及”“你替我接下”提供急迫与关系重量，却没有说明赵母本人要离开，也没有说明票给谁。记忆仍有身体感与情绪，不只是线索搬运；雨停恰好切在递票动作上，为 Ch2–3 保留了核验空间。

### 6. Ending Hook — PASS

唐荔已经去锁灰衣并到后院关排气扇，明确离开账页视线。谢念在 2016 页前先缩手、跳页，再主动拨回，公平表现她对过去的回避而未泄露“让我忘掉”。最终登记完整包含谢念、蓝白校服、本人、2016-07-19、未还；之后只保留短促反应并停在“未还”，读者问题准确落在“为什么她自己的衣服会登记在这里”。
