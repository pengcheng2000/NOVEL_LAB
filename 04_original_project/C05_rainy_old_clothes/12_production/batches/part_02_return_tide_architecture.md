## 2. Part II Contract

## 3. Meaning of “返潮”

**主层意义：被压住的选择权与责任，借寄雨行打开的公共入口重新渗回当下。**

“返潮”不是又一次降雨，也不是旧事自动复活。它指已经被出售、继承、转交、沉默或包装成内容的旧衣关系，重新向现在的持有人、穿衣人、家属、店铺和平台提出权利要求。2016 线同样以现实主张和关系责任逐步回返，而不是靠连续闪回倾倒答案。

- 不连续使用档案室、仓库、旧址、名单作为调查容器。

- 不把流量写成爆红、经营升级或无限订单；重点是复杂度，不是规模。

## 5. Core Engines

1. **Engine A — Consent / Source Conflict（45%）**：公开业务带来“能修不等于能拍、能拥有不等于能讲、能交不等于能读”的冲突。
2. **Engine B — First-Slot Qualification（30%）**：不再只追孙正下落，改查工装实际穿着、发放、回收与合法关系主体。
3. **Engine C — Shop / Debt / 9/5（25%）**：新增工作量挤压调查与生产，退款、停拍、预约和搬迁准备消耗刚获得的喘息。

三线必须在每个小弧中至少交叉两次。任何公开案例若不能改变第一格方法、核心关系或店铺状态，不进入正文。

## 6. Xie Nian Active Goal

**主 Goal：在不把寄雨行变成窥私内容工厂的前提下，建立一套自己愿意公开承担的来源—授权—同意分流流程。**

次 Goal：

1. 把第一格调查从“找名字”推进为“确认真实穿衣人与合格交付关系”；
2. 让普通业务活到 9/5，同时开始准备物品去留和可迁移的普通工位方案。

谢念依靠平台运营、衣物痕迹判断和纠纷核验经验行动。她可以要求材料、暂停处理、咨询专业人士，但不得出口成法条或替法院确认物权。

## 7. Tang Li Function

- **ACTIVE PRESSURE**：普通订单、返工与公开合作排期增长；每暂停一件争议衣，都直接损失工时与收入。
- **ACTIVE CHOICE**：唐荔主导前台建立可执行的接件分流与客户确认，不把排期权交给秦沛团队；她选择保住普通手艺人的劳动边界，而非替谢念守秘密。
- **RELATIONSHIP FUNCTION**：她与谢念围绕“先接活还是先核来源”发生职业冲突，最后形成临时工作流程；私人友情不升温，真实隐瞒动机不揭示。

## 8. Zhou Xu Function

- 公共内容带来少量到店人流，可能挡住施工通道、监测点或形成现场安全投诉；这使周序的职业责任直接进入店铺经营。
- 他提供公开、同样适用于整条老街的安全与资产搬移要求，不为谢念开私人通道。
- 他要求寄雨行实行预约、保持门前通行，并开始区分可移动经营设备与建筑附着物；帮助不是免费调档，而是减少项目风险。
- 其父录音后半段在 Opening Arc 完全冻结。他继续留下，是因为寄雨行的公开化已经影响其工程职责，而第一格现实调查也可能改变父亲责任链。

## 9. Qin Pei Function

- **想获得**：稳定、可复制的普通修补内容管线，本地品牌信誉，以及持续观察寄雨行边界的商业位置。
- **与谢念一致**：都不能让合作因隐私投诉迅速翻车；都需要普通业务产生现金与可信度。
- **与谢念冲突**：秦沛倾向认为现持有人签署拍摄同意已足够；谢念坚持公开前还要识别衣物所承载的他人隐私与来源争议。
- **代价与筹码**：当 Opening Case 停拍时，秦沛必须承担内容空档并要求替换素材/明确处理时限；她不提供第一格新物证。灰工装控制权继续保留。

## 10. Yu He Function

Ch21–23 让余禾恢复可见度，但只处于普通运营层：整理咨询、标注是否允许拍摄、识别复制粘贴的猎奇故事和维护前堂排期。他不得接触后堂、《承衣簿》、第一格或读衣机制。

余禾不是“网络万能助手”；他只能帮助看见问题规模与公开传播风险，最终判断仍由谢念、唐荔和当事人承担。

## 11. Consent / Source Conflict Model

### Three Separate Systems

| 体系 | 本弧只回答什么 | 不能自动推出什么 |
|---|---|---|
| A. 现实所有权 / 占有 / 来源 | 谁当前持有、从哪里取得、是否存在争议迹象 | 不自动取得前穿衣人的隐私叙事权 |
| B. 现实同意 / 隐私 / 授权 | 谁同意修补、拍摄和公开到什么范围 | 不自动满足寄雨行特殊受理资格 |
| C. 寄雨行内部资格 | 谁有权交、谁与穿衣人有真实关系、谁承担后果 | 不替代现实所有权或公共证据 |

### Conflict-Type Comparison

| 类型 | Opening Arc 适配 | 裁决 |
|---|---|---|
| 本人送衣但牵涉他人隐私 | 强，但容易靠删故事迅速解决 | 后续使用 |
| 死者遗物家属意见冲突 | 情感强，但与 Ch1 死者衣语法相近 | 暂缓 |
| 二手买家合法持有，但前穿衣人未同意 | 最能显示三体系错位，并镜像红外套/灰工装“穿过不等于拥有” | **选为 Opening Case** |
| 受托代送、授权范围模糊 | 容易变授权书程序剧 | 后续使用 |
| 多人共同使用一件衣 | 会逼近尚未完整公开的多人穿衣规则 | 暂缓 |
| 来源真实但目的恶意 | 适合中段公共后果 | 后续使用 |
| 伪造故事/猎奇测试 | Part I 已有假来历旧规划影子，开局再用会重复 | 只作背景噪声 |

### Opening Demonstration Case

- **核心人物**：梁女士（仅用姓氏，MAY RECUR），同城二手买家；通过普通二手渠道购得一件暗绿棉夹克，有常规交易记录，想修改尺寸并同意进入普通合作内容。
- **辅助人物**：前穿衣人的成年女儿（不命名，LOCAL ONLY）；从合作预告画面中的可见修补痕迹认出衣物，称仍在世的母亲从未同意亲属处置或公开其经历。
- **冲突**：梁女士的现实占有与普通修补意愿可能真实；前穿衣人的隐私主张也可能真实；双方都没有资格替另一方决定公开故事，更没人自动取得特殊读取资格。
- **阶段结果**：停止拍摄和不可逆改衣，保留咨询与来源核验；梁女士选择追查卖方授权而非放弃衣物，案件不在 Ch23 情感结案。

## 18. Anti-Proceduralization

1. 每次来源问题先表现为人物要付的代价：停拍、退款、工期、名誉、失去衣物或被家人否认；文件只做一拍。
2. 三套体系由三方不同诉求体现，不让谢念连续宣读规则：现持有人要修，前穿衣人要隐私，秦沛要内容，唐荔要工时。
3. 证据只改变可选行动，不替人物作最终裁判；照片、订单记录、修补痕迹均保留解释余地。
4. 需要法律专业判断时，只写暂停、咨询、保留材料；不让谢念自创法条。
5. 每章至少一个具体动作承担主题：撤下画面、停止剪线、退回衣物、重排工位，而非会议总结。

## 20. Ch21–23 Opening Arc

### Opening Image

Ch20 开门后的次日上午，前堂不是人山人海，而是少量新增旧衣、待回复咨询与唐荔尚未完成的普通订单挤在同一张裁床上；门内《服务须知》清楚可见，门外施工通道仍在使用。

### Opening Pressure

秦沛需要首轮普通内容素材，唐荔需要把新增询问变成可结算工时，周序需要门前不影响施工安全；谢念必须在尚无成熟流程时接住第一件“买得到、未必讲得了”的衣。

### Opening Question

**一件通过普通交易买来的旧衣，现持有人可以买到修补权，却是否也买到了公开前穿衣人生活的权利？**

### Three-Chapter Curve

- **Ch21：入口撞门**——梁女士带暗绿棉夹克与普通交易记录到店，愿意修补和拍摄；谢念初步受理普通评估，三方对“同意已经足够”理解不同。
- **Ch22：权利错位**——前穿衣人的女儿提出隐私与来源异议；谢念叫停画面与不可逆改衣，秦沛、唐荔分别承担内容和工时损失；周序因客流/施工通道提出现实约束。
- **Ch23：建立分流**——不判谁最终拥有，建立普通修补、公开叙事、内部资格三线分流；梁女士选择追查卖方授权，案件保持开放。谢念把同一方法用于第一格，确定下一步应找工装发放/回收经手链。

## 21. Risks

1. **程序剧化**：把人物冲突写成逐条审授权文件。
2. **单元剧闭环**：Ch23 让双方和解、衣服修好、案例离场。
3. **谢念律师化**：使用法条、替争议双方认定物权或授权效力。
4. **第一格停摆或抢戏**：完全不推进，或反过来三章都查孙正。
5. **公开规模膨胀**：把本地增量写成爆单、热搜或全国争议。
