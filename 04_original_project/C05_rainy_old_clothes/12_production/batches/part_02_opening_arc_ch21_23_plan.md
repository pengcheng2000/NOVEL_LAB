## 1. Three-Chapter Mini-Arc

**Starting State**：寄雨行刚通过有限普通合作进入本地公众视野；收入只获得喘息，前台开始出现少量新咨询；灰工装仍在秦沛仓储，第一格资格未决；9/5 不变。

**Escalation**：一位拥有普通二手交易记录的现持有人要求改衣并允许拍摄；前穿衣人的女儿随后提出来源和隐私异议，使“有衣、有付款、有现持有人同意”不再等于“可以公开其故事”。

**Decision**：谢念拒绝替双方判定最终物权，也不启动任何特殊流程；她把普通修补、公开叙事和内部受理资格拆成三条独立路径。唐荔与秦沛分别承担停工、停拍代价，梁女士主动追查卖方授权。

**Ending State**：Opening Case 未结案但已改变寄雨行工作法；第一格调查由“找孙正本人”转成“先找原仓库工装发放/回收经手链”；普通经营开始按 9/5 前可完成度与来源风险分流。

## 3. Opening Case

- 梁女士通过普通二手渠道购买一件暗绿棉夹克，能出示常规交易记录；她想改短袖长，并同意秦沛团队把普通修补过程用于合作内容。
- 拍摄预告中的可见修补痕迹被前穿衣人的成年女儿认出；对方称母亲仍在世，并未同意某位亲属处置衣服或把其经历公开。
- 梁女士不是猎奇骗子：她真实付款、真实喜欢衣服，也不愿被当成偷衣者。
- 异议方也不是自动正确：她能证明衣服与母亲有关，却不能仅凭亲属身份替母亲完成全部权属主张。
- 阶段处置：撤下/暂停相关画面，停止不可逆改衣；保留咨询与材料核验。梁女士带着衣物继续追查卖方授权，允许后续回场。

## 4. Why This Is Not an Anthology Unit

1. 案件在 Ch23 不情感结案，人物和来源争议可回场。
2. 它使唐荔失去已排入的工时、秦沛失去一段内容、谢念承担退款/声誉压力。
3. 它永久改变普通接件和拍摄授权流程。
4. 它直接推翻第一格的便利假设：“孙正”标记不等于孙正实际穿过。
5. 它让余禾、周序与四组核心关系进入第二部新位置，而非只服务客人。
