# FINALIST_2 — C06《本草遗方》

> Phase 4 · 2026-09-13 · 总分 82（并列第一）｜续航 9/10（并列最高）

## 为什么它值得继续

1. **长篇续航与商业形态的双最优**：41 味删方=天然闭合的章节地图（清单即结构×清单即线索）；网文 200–400 万字与短剧/动画多形态路径同时成立——8 候选中唯一"百万字网文+国风短剧+设定集衍生"三线全通的设计。
2. **世界观资产可独立复用**：41 味原创药物设定（仿古条目：药名/性味/主治/代价/禁忌）是可脱离剧情存在的资产（设定集/条目卡/周边）——"负空间数据库"方法（典籍删除痕迹作为内容来源）标记为 ORIGINAL_PROJECT_DISCOVERY，可反向入库。
3. **守恒律 + 公版数据库的化学反应**：MM34（本草纲目删方）×MM14（条目化的明码标价+可分担的责任制）——两个 TOP30 基因的组合在本作产生了第三个系统（伦理账本），非简单叠加。
4. **国风品类的空白位**：县城国风（非架空国风）+人情案件（非怪谈档案）的定位避开了民俗惊悚红海；中医药文化的考据感自带可信度与话题度。

## 最大优势
**"药治的是病，删方治的是说不出口的中国式人情"**——每案的单元爽（药到病除）与情感爽（人情真相）双兑付，且代价系统（分担制）天然防止爽点通胀：这是网文长跑最健康的奖励结构设计（MM12 补偿型混用自觉）。

## 最大风险
1. **中医题材的争议红线**：删方疗效与现实医学的边界必须绝对清晰（架空声明+条目虚构标注+不出现真实病名的"治愈"承诺）——处理不慎即舆论反噬，这是本作唯一的重大风险项。
2. **爷爷缺席线的贯穿难度**：全书情感母线（隔空师徒）依赖朱批/账本/口述的"遗物教学"，写得薄则长线塌、写得密则单元被挤——配比是工艺难点。
3. **41 味的均质化陷阱**：中段单元易陷入"药名+病症+代价"的模板重复（抗疲劳需达到"换规则"级而非"换皮"级——中期需要开出改变玩法结构的药）。

## Phase 5 优先解决
1. **41 味药的完整设定表**（先于大纲：每味条目+对应案件类型+在传承链中的位置——世界观资产先行）。
2. **合规声明方案**：架空边界的法务级措辞+每集条目卡"本作虚构"标注规范。

4. **爷爷之死的三版本证词细纲**（传闻逼近结构需要严密的版本证据链）。
