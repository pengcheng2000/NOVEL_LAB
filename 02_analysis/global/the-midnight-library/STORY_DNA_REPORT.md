## B. Core Story Promise

**"如果你能免费试穿每一种人生，试到最后你会发现：你真正想要的一直是你已经拥有的那个。"——遗憾的解药不是另一种人生，是对这一种人生的重新看见。**

- **PREMISE** [TEXTUAL+SECONDARY, HIGH]: 35 岁的 Nora Seed 在人生最灰暗的夜晚自杀，醒来发现自己处于生死之间的图书馆——每本书是一个"如果当初"的人生版本。
- **CORE_FANTASY** [HIGH]: **重选人生**（do-over 欲望的图书馆化）——但本书做了一次反转：不卖"另一种人生更好"，卖"试遍所有人生后与本人生和解"。
- **CORE_EMOTIONAL_PROMISE** [HIGH]: 治愈（catharsis via 累积的小顿悟）。预期情绪路径：共情她的绝望 → 每个人生的兴奋 → 每次的失落 → 逐步逼近"活着本身就有价值"的终点。
- **CORE_CURIOSITY_PROMISE** [MEDIUM]: (a) 这一次的人生会是什么样、好在哪、坏在哪；(b) 她最终会留在哪个人生/能否回到原人生。

## C. Protagonist Engine

- **Starting Position** [TEXTUAL+SECONDARY, HIGH]: 35 岁，英国小镇 Bedford，音乐梦碎（乐队解散/放弃钢琴）、未婚、被解雇的唱片店店员、弟弟疏远、猫刚死、母亲已逝——人生遗憾清单齐全。**开局是一张"失败清点表"，这正是主题的实验器材**。
- **Desire** [MEDIUM]: 最初 = 逃离；深层 = 想知道"我的人生到底是哪一步走错了"。
- **Fear** [MEDIUM]: 证实"我的人生本可以更好而我没做到"。
- **Weakness** [TEXTUAL+SECONDARY, MEDIUM]: 抑郁性的归因偏差——把所有中性事件解释为自己的失败（第 1 章与图书管理员的对照：Mrs. Elm 说"无限可能"，Nora 听到的是"无限失败空间"）。
- **Unfair Advantage**: 无（这不是爽文引擎）——优势是**图书管理员 Mrs. Elm**：一个对她有私人记忆的引导者角色。
- **Relatability** [HIGH]: "三十多岁、一事无成、错过了一切"是最大公约数的当代焦虑——遗憾清单（没坚持钢琴/没和那个人在一起/没去远方）人人可填。
- **Character Contradiction** [MEDIUM]: 她自杀是因为觉得人生无望，但她试穿每个人生时的投入度证明她想活——矛盾本身就是全书论证。

## D. Reader Addiction Engine

- **PRIMARY LOOP**（人生试穿循环，SECONDARY+目录结构, HIGH）:
  选一本"如果当初" → 进入新人生（身份/技能/关系瞬间继承，跳过获得过程——**do-over 快感的最大化设计**）→ 初期惊艳（幻想兑现）→ 裂缝出现（每个人生自带它自己的遗憾/代价）→ 幻灭或被迫退出 → 带着一条新认知回到图书馆 → 下一本。
  为什么可重复：**平行人生是无限的场景发生器**（摇滚明星/冰川学家/奥运选手/酒馆老板/酒庄主……目录直接可见人生类型序列），每次循环结构相同但内容全新；且每次循环向终点（对根生活的重新理解）推进一格——单元剧外壳 + 连续剧内核。
- **SECONDARY LOOP**（遗憾清单更新循环，MEDIUM）: 每个人生揭示"当初那个选择其实通向什么"，遗憾清单上的项目被逐条重新定价。
- **LONG-TERM LOOP**（图书馆本身的谜，MEDIUM）: 图书馆/管理员的工作机制、她与 Mrs. Elm 的真实关系、为什么是她——薄层悬念，防止单元循环疲劳。

## E. Reward Engine

- **主奖励**: **体验型 reward**——每个新人生是一次免费的人生模拟（读者借 Nora 玩遍所有职业/关系/地理，一次付费全家桶）[HIGH]
- **次奖励**: MYSTERY（每个人生"哪里不对劲"的侦探感）；EMOTIONAL_PAYOFF（结尾的"选择活着"）
- **BUILDUP → PAYOFF**: 反转式结构——**每个 reward 的兑现时刻（人生变好）就是它的失效时刻**（发现新遗憾），长期 payoff 是全书的治愈结论。爽点引擎被故意做成递减序列：读者从"换人生好爽"逐渐被训练为"换人生没用了" [INFERENCE, MEDIUM]。

## F. Relationship Engine

- **Nora × Mrs. Elm（图书管理员）** [TEXTUAL+SECONDARY, HIGH]: 引导者 + 记忆见证人——她是 Nora 中学图书馆管理员，认识少女 Nora。机制 = **温暖的权威**：制定规则（只能读不能带走）、提供解读、不评判。为什么读者想看：她是唯一贯穿所有平行人生的关系锚点。
- **Nora × 弟弟 Joe** [SECONDARY, MEDIUM]: 遗憾清单核心项（"如果我支持了他的选择"）——亲情线提供最大的单次试穿冲动与最大的终局和解。
- **Nora × 各人生的关系替身** [MEDIUM]: 每个人生自带一套预装关系（丈夫/女儿/乐队队友），Nora 以陌生人身份进入亲人的身体记忆——**"你认识的人不认识你"是每个新人生自带的高浓度情感场景**。
- **机制提炼**: 本书关系引擎的本质 = **关系的重新定价**：同一批人在不同人生里以不同版本出现，读者获得的是"关系是条件函数还是人的函数"的连续思考。

## G. Conflict Engine

- **Obstacle Generation** [SECONDARY, MEDIUM]: 每个人生自带内嵌冲突（成功的代价预装在成功里），无需外部反派；叠加图书馆规则的约束（时间流逝/无法停留的危机感）。
- **STORY RENEWAL ENGINE** [目录证据, HIGH]: **人生类型轮换**——目录可见明确的人生类型序列（摇滚明星线：19–22 章；冰川科学家线：26–33 章；酒庄线：51–52 章……）。单元剧结构天然抗疲劳：设定可无限更换而主角引擎不变。
- **收敛信号** [目录证据, HIGH]: 目录后半段出现"迷失在图书馆 → 完美人生 → 她已经不在了 → 不许放弃 → 苏醒 → 终局"——结构从发散转向收敛，说明作者有意识控制"试穿疲劳"的出现位置。

## H. Hook Engine

- **Opening Hook** [TEXTUAL, HIGH]: 第一段三个词完成生死定位——"诺拉·希德决定去死。"（中译文）直接、平静、不容回避；紧接着闪回 19 年前的棋局——用"无限可能"的过去反衬"全部落空"的现在。
- **章节钩子** [目录结构, MEDIUM]: 章节极短（全书 72+ 章）+ 标题具体到物件与场景（"鱼缸""三轮车""薄荷茶"）——标题本身就是微型悬念（这个词在人生里意味着什么？）。
- **平行线钩** [目录证据, HIGH]: 三处"社交媒体动态"标题（倒数第二条动态/最后一条动态）——诺拉在生死之间仍在发帖，平行叙事线提供独特悬念（她在向谁发？谁能看到？）。
- **长期钩**: "她最终去哪儿"（root life 的存亡）[HIGH]。

## I. Groundedness Engine

- **文本证据** [TEXTUAL, HIGH]: 第 1 章的锚点质量极高—— Bedford 小镇、中学图书馆的午后、母亲用胶带粘她耳朵的细节（日常暴政式亲子关系）、考试焦虑。**"母亲的胶带耳朵"是一个物件级的遗憾来源**：把宏观主题（人生遗憾）落到最具体的身体记忆上。
- **幻想世界的接入策略** [MEDIUM]: 图书馆机制完全借用现实经验（图书馆规则/管理员/棋局——第 1 章的棋局直接是机制的隐喻：每一步选择改变全局），读者零学习成本。
- **遗憾清单的现实性** [HIGH]: 遗憾全部来自最常见的普通人生节点（职业放弃/亲人疏远/宠物死亡/婚姻未成）——groundedness 是治愈可信的前提。

## J. Fantasy / Desire Engine

重选人生（核心）；逃离普通生活（前期被满足后期被解构）；知道别人不知道的信息（她带着根生活记忆进每个人生 = 信息优势的治愈系用法）；**最终欲望：获得"继续活着"的理由**——把爽文欲望结构倒装成治愈结构是本书的最大商业差异化。

## K. Emotional Engine [MEDIUM]

情绪债务：开篇即最大负债（绝望 + 自杀意图——情绪从最低点起步）。每个人生循环 = 借新债（期待）→ 小额还款（惊艳期）→ 债务转移（新遗憾）。全书的最终清偿 = 一个认知而非一个事件（"遗憾不是人生的对立面，是人生的一部分"式的领悟）。**情绪兑现完全依赖认知升级而非情节奖励——文学向治愈的结构特征**。

## L. Distinctive Mechanisms

- **L1. Life-Fitting Room（人生试衣间）** [SECONDARY+目录, HIGH]
  - Function: 把 do-over 幻想结构化为可无限重复的单元剧容器。
  - Setup: 图书馆机制（每本书=一个人生）+ 遗憾清单（候选人生目录）。
  - Escalation: 人生类型按"她最深的遗憾"排序递进，越后期的人生越接近她的核心创伤。
  - Payoff: 每次试穿同时兑付 fantasy（新人生体验）与 theme（每个人生自带遗憾）。
  - Transferable Principle: 把"重选"幻想做成可枚举、可循环的容器，用容器内的规律性失望递进论证主题——单元剧结构与主题论证完全同构。
- **L2. Instant-Inheritance Entry（即时空降人生）** [SECONDARY, MEDIUM]
  - 进入新人生时跳过全部获得过程：技能/关系/身份瞬间继承。
  - Transferable Principle: do-over 快感的最大化 = 只体验"拥有"不体验"挣得"；代价是不属于你的记忆会在细节处暴露（"你认识的人不认识你"）。
- **L3. Regret Repricing（遗憾重新定价）** [SECONDARY, MEDIUM]
  - 每个平行人生揭示一个当初选择的完整后果——遗憾从"损失"被重新标注为"信息"。
  - Transferable Principle: 让主角亲历每个"如果当初"的真实结局，用体验而非说教完成心态转变。
- **L4. Dual-Anchor Guide（有私人记忆的引导者）** [TEXTUAL+SECONDARY, MEDIUM]
  - 引导者不是抽象规则而是认识少女主角的具体的人——机制入口即情感入口。
  - Transferable Principle: 奇幻机制的讲解者应与主角有前史；规则交割与情感充值合并成同一场戏。
- **L5. Object-Titled Micro-Chapters（物件标题微章）** [目录证据, HIGH]
  - 72+ 章以具体物件/场景命名，章节极短——标题做悬念，短章控节奏，治愈书做出翻页速度。
  - Transferable Principle: 用"具象名词标题"给短章预装好奇（这个词在新人生里意味着什么？），低成本提高翻页率。
- **L6. Reward-Decay Training（奖励递减训练）** [INFERENCE, MEDIUM]
  - 前几个人生是大 reward（成名/爱情/冒险），后期人生递减并转向内在（平静的生活/普通的爱）——读者的 reward 阈值被有意重置。
  - Transferable Principle: 治愈系长篇可以系统性地"驯化"读者的爽点预期，把翻页动力从 reward 转移到 theme。
- **L7. Fable-Premise Reality-Anchor（寓言前提 + 现实锚点）** [TEXTUAL, HIGH]
  - 前提是寓言级（生死之间有图书馆），但第 1 章的锚点全是最具体的日常（胶带耳朵/中学图书馆/考试焦虑）——寓言的可信度由细节密度支付。
  - Transferable Principle: 设定越抽象，开篇的日常锚点就要越具体——用密度对冲高度。

## 原创性风险

- **GREEN**: L1–L7 全部原理；单元剧试穿结构、遗憾重定价。
- **YELLOW**: "生死之间的图书馆 + 图书管理员引导者 + 遗憾之书"整体意象组合识别度很高（含本书标志性意象）；"试穿平行人生后选择原人生"的治愈结论路径。
- **RED**: The Midnight Library / Nora Seed / Mrs. Elm / Bedford 命名；普拉斯引言开篇用法；具体人生清单（摇滚明星/斯瓦尔巴特冰川学家等的具体组合）。
