## 2. 什么机制重复出现？

### 与 GLOBAL 组共通（跨文化公约数）
- **物件清单现实主义（5/5）**：人生的秘密藏在午餐盒/白裙子/纹身/邮票/驯鹿里——与 GLOBAL 组的 M4 物件锚点完全互证。**15 本中最强的跨文化公约数。**
- **结构性弱势开局（5/5）**：少年窥视者/被骗者/背锅吏/消亡部落/被抄家者。
- **断言-反转延迟兑现（4/5）**："不可能"的荔枝运到了；"不存在"的文城住下了；"会消失"的部落讲了百年。

### 本组特有（文学出版的机制签名）
- **C1. 时间作为结构容器（4/5）**：一日百年（额尔古纳）/ 双时代回声（繁花）/ 证人跨 60 年接力（人生海海）/ 一生寻一个谎言（文城）——**纯文学长篇几乎不用悬念结构，用时间结构替代**。
- **C2. 叙事的"转场机器"（3/5）**：饭局八卦（繁花）/ 证人证言（人生海海）/ 补叙重估（文城）——文学长篇靠转场装置维持翻页，不靠章末钩子。
- **C3. 反爽点伦理（4/5）**：reward 系统被道德化（长安的荔枝的代价账本）或悬置（文城的好人不胜）——**文学出版物的差异化恰恰是对网文爽感的系统性反动**。
- **C4. 时代作为无脸反派（5/5）**：与 GLOBAL 组的"制度反派"同源，但中文文学的版本更重：文革/市场化/现代性是 5 本共同的压强来源。

## 3. 哪些完全不同？

- **唯一的商业小说样本**：长安的荔枝是本组中唯一的"爽感驱动"作品（工程分解+死线倒计时）——它是马伯庸对网文机制的文学化提纯，恰好坐落两组之间（本组与网文组的桥梁样本）。
- **唯一无主角欲望的**：额尔古纳河右岸（欲望已退场）——治愈系的极端配置。
- **唯一无成瘾设计仍大成的**：繁花——靠语言资产+身份消费，证明该路径存在但不可复制。

## 4. 哪些最"上头"？

1. **长安的荔枝的工程攻关循环**——本组唯一的真成瘾设计，环节分解+死线+金句升维三件套齐备。
2. **人生海海的传闻逼近**——多版本真相的拼图消费（读者当侦探）。
3. **额尔古纳河的萨满守恒律**——每次跳神都是预告的悲剧（最残酷的"翻页理由"）。
4. **繁花的连线题**——参与式回声。
5. **文城的读者知地差距**——反向信息差的钝痛。

## 5. 哪些最接地气？

1. **长安的荔枝**——房贷/背锅/KPI 的全息职场映射（本组出圈第一动因，2025 双改编）。
2. **繁花**——物件编年城市史（接地气作为内容本体）。
3. **额尔古纳河右岸**——反向接地气（异质细节=现实感）。
4. **人生海海 / 文城**——时代质感接地（依赖历史细节的密度）。

## 6. 哪些最容易迁移？

- **迁移成本最低**：长安的荔枝的 L3 流程反派 + L5 古今职场全息映射（任何时代/行业题材可整体套用）；繁花 L1 不响母题（纯文体装置）。
- **迁移价值最高**：额尔古纳河 L2 守恒律魔法（给任何力量系统装上悲剧发生器）+ L4 万物亲属化（治愈 IP 的世界观底层）。
- **迁移风险最高**：繁花的方言资产（吴语区专属）；额尔古纳河的题材整体（纪实性强，架空即失真——只能迁移机制，不能迁移题材）。

## 7. 哪些最适合 AI 视频？

1. **额尔古纳河右岸（8）**——自然大景+少人物+无特效+画面驱动 = AI 生成最强项。
2. **长安的荔枝（8）**——环节分集+强美术+已验证改编路径。
3. **繁花（7）**——时代美术友好但群戏表演是 AI 弱项。
4. **人生海海/文城（6）**——多声部/长程情绪结构影视化损耗大。

## 8. 跨书元结论（含与 GLOBAL 组对照）

1. **中文文学出版的市场成功路径与 GLOBAL 大众书不同**：GLOBAL 组靠"结构性弱势+制度反派+延迟兑现"的公约数（类型化可复制）；本组 5 本靠**不可复制的单一资产**（题材独占/语言资产/历史全息映射/文体发明）取胜——一边是产品逻辑，一边是作品逻辑。**做原创 IP 应主要从 GLOBAL 组借机制、从本组借质感与时间结构。**
2. **时间结构是纯文学对悬念结构的替代品**——四种时间容器（一日百年/双时代/证人接力/一生一诺）全部可移植到类型叙事中做骨架升级。
3. **"反爽点"本身可以成为卖点**，但需要至少一项顶级不可复制资产兜底（文学奖背书/名导改编/直播推荐——额尔古纳河 2023 爆卖证明**渠道情绪**能重启动一部 18 年前的书）。
4. **物件清单现实主义是 10/10 命中的第一公约数**——两组、十个品类、东西方全部命中，可视为本项目目前最可靠的发现。
