## 2. 什么机制重复出现？

### 网文的工业化共识（5/5 命中）
- **W1. 单元容器 + 长线底牌的双时间表（5/5）**：案件/游戏/神话/遗憾/商机作为可无限更换的单元容器，主角身份或世界真相作为全书级底牌。**这是网文百万字续航的核心架构**——与 GLOBAL 组的"单本延迟兑现"同构，但工业化为"容器化批量生产"。
- **W2. 清单即结构（4/5）**：遗憾清单（重生啊）/风口清单（都重生了）/神话数据库（斩神）/案件排期（大奉）/证人清单（人生海海——跨组出现）。**可枚举的清单 = 章节地图 = 作品体量规划文档。**
- **W3. 章末钩工业化（5/5）**：断章艺术是网文的基本功，不赘述——但值得记录各书的差异：大奉/斩神靠事件断点，十日靠回合悬念，重生系靠"下一个节点预告"。
- **W4. 金手指的"正当化"竞争（5/5）**：5 本的金手指全部避免了"纯系统发放"的廉价形态——记忆/思维方式/神话联结/智力/记忆，**都在人物内部**（internalized cheat）——2020s 头部网文的共同进化方向：金手指必须可被尊重。

### 与前两组的互证
- **物件清单现实主义 13/15**（本组以"时代物件/神话物件"形式出现）。
- **制度反派（4/5）**：衙门/游戏规则/神话秩序/时代——网文版的独特处理：**允许主角最终接管制度**（大奉）或玩弄制度（十日）——这是与文学组（被动承受）和 GLOBAL 组（生存抵抗）的根本差异。

## 3. 哪些完全不同？

- **情绪基调的三档**：日常流（低强度持续愉悦——电子榨菜）/ 幽默流（喜剧维保系统）/ 热血流（大情绪高潮）——三种情绪工程对应三类读者疲劳曲线，互不通用。
- **唯一无金手指争议的**：十日终焉（纯智力）——金手指内化到极致即消失。
- **社交层设计**：大奉的地书群聊是 5 本中唯一的**主角间社交系统**发明——网文对"关系性"的产品化探索样本。

1. **十日终焉的死亡游戏循环**——容器每轮换玩法（最高级抗疲劳设计）+ 读者同步推理的参与式结构。
2. **大奉的案件侦破循环**——单元容器的四任务化（爽点/开图/人物/伏笔）是效率天花板。

## 6. 哪些最容易迁移？

- **迁移成本最低**：W1 双时间表（任何长篇的骨架级移植）；W2 清单即结构（规划工具即结构工具）。
- **迁移价值最高**：大奉的 L3 匿名社交层（原创群像/互动内容的独特引擎——**15 本中唯一的社交机制发明**）；十日的 L1 规则文本武器化 + L3 玩法换档。
- **迁移风险最高**：斩神的神话题材整体（神话数据库是公共资产，但"斩神"术语与病院配置已绑定）；宣言式书名句式（已被模仿至失效边缘）。

2. **重生系两本（6）**——制作门槛最低但同质化最重。

## 8. 跨书元结论

1. **网文的本质是"容器工程学"**：15 本横跨三组，网文组最清晰的启示是——长篇可持续性的来源不是情节而是**可更换的单元容器 + 不换的主角引擎 + 逐层开采的内容数据库**（案件/神话/风口/遗憾/规则）。这套"容器架构"可直接移植任何题材的原创长篇。
2. **金手指的进化方向是"内化与克制"**——从系统发放 → 思维方式 → 纯智力。原创设计的金手指应遵守：能力必须在人物内部 + 能力必须有代价或边界（额尔古纳河的守恒律是文学版的同一法则）。
3. **"清单即结构"是 15 本中第二强的公约数**——清单（遗憾/风口/证人/神话/规则）同时充当章节地图与体量规划工具，是可直接落地的写作工程方法。
4. **网文组对 AI 视频的整体适配度最高**（均分 7.2 vs GLOBAL 7.4 但结构适配更好：单元分集、每集可独立传播的反转切片、公版美术题材）——**原创 AI 视频 IP 的第一学习对象应是本组的结构 + GLOBAL 组的公约数**。
