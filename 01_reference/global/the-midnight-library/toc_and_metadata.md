## 结构观察（仅基于目录，不涉及正文）

- 章节极短、标题具体（"鱼缸""三轮车""薄荷茶"）→ 单元剧式"试人生"结构
- 出现明显的"人生类型"序列：摇滚明星人生（《火》/名声/银河）、冰川科学家人生（斯瓦尔巴特/永冻层/朗伊尔之夜）、奥运选手人生（转圈圈？）、酒庄人生、酒吧人生
- 三处"社交媒体动态"标题（倒数第二条动态/最后一条动态）→ 诺拉在尝试人生期间同时发帖的平行叙事线
- 目录后半出现明确的收敛信号：迷失在图书馆 → 完美人生 → 她（图书馆管理员）已经不在了 → 不许放弃 → 苏醒 → 终局
